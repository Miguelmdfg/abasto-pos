# System Architect — Delivery Format Template

```
CONTEXT: [what was requested and what was found]
CURRENT STATE: [how it is implemented today, with code references]

ARCHITECTURAL DECISION:
  - [concrete decision]
  - Justification: [why this option and not another]
  - Alternatives discarded: [with reason]

PACKAGE IMPACT:
  - [package]: [what changes or is created]

CONTRACTS DEFINED/MODIFIED:
  - [endpoint/service]: [request/response/behavior]

DEPENDENCIES WITH OTHER AGENTS:
  - data-architect: [if schema changes needed]
  - security-compliance: [if permissions or sensitive data involved]
  - data-experience-architect: [if available data for UI changes]

TECHNICAL DEBT DETECTED:
  - [if applicable, what exists today that should be corrected]

SCALE CONSIDERATIONS:
  - [how this decision behaves with N institutions, multiple countries, growing volume]
```
